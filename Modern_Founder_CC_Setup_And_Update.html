Existing Students

Update With One Command

Open your business folder in Antigravity, open a terminal (Terminal > New Terminal), then paste the command for your system:

Mac / Linux

cd modern-founder-skills && git pull && bash setup.sh

Windows

cd modern-founder-skills && git pull && setup.bat

Three things happen in order: you cd into the repo, git pull downloads the updates, and the setup script copies the new skills into your .claude/skills/ folder.

After the Update

1

2

Reopen Antigravity and open your business folder.

3

Don't just close the window. Antigravity caches skills at startup - you need to fully quit or new skills won't show up.

Step 2 of 7

Create Your Business Folder

1

Create one folder for your business anywhere on your machine. Name it whatever you want: MyBusiness, Acme Ltd, etc.

2

In Antigravity: File > Open Folder > select your business folder.

3

Open a terminal: Terminal > New Terminal. It will open inside your business folder.

This folder is your business folder root. Every command in the course assumes your terminal is here. Not inside a subfolder.
Step 3 of 7

Clone the Repo

From the terminal (still at your business folder root), run:

git clone https://github.com/JoshFrySBS/modern-founder-skills.git

This creates a modern-founder-skills subfolder inside your business folder.

Do not rename this folder. Keep it as modern-founder-skills exactly. Every command in the course, every update instruction, every troubleshooting tip assumes this name. Renaming it to 03_Modern Founder Skills, MFS, or anything else will break every update.
Step 4 of 7

Run the Setup Script

The setup script copies the skills from inside the repo to your business folder root so Claude Code can find them.

Mac / Linux

cd modern-founder-skills && bash setup.sh

Windows

cd modern-founder-skills && setup.bat

You should see output confirming the copy succeeded. A new .claude/skills/ folder will appear at your business folder root.

Step 5 of 7

Add Your API Keys

1

In the Antigravity sidebar, open modern-founder-skills/ and find .env.example.

2

Right-click it, Copy, then right-click the file list, Paste. Rename the copy to .env (remove .example).

3

Open .env and paste your keys:

# Instantly API key (Settings > Integrations > API) INSTANTLY_API_KEY=paste_your_key_here # Anthropic API key (console.anthropic.com > API Keys) ANTHROPIC_API_KEY=paste_your_key_here
Never share your .env file. Your keys stay private - the .gitignore makes sure they never get committed.

Troubleshooting

The common errors, and how to fix them.

Common Error #1

"cd: no such file or directory: modern-founder-skills"

Your terminal is open in the wrong folder. The command expects you to be at your business folder root (the folder that contains modern-founder-skills/), not inside a subfolder like Business Docs/.

Find out where the repo actually is on your Mac / Linux:

find ~ -type d -name "modern-founder-skills" 2>/dev/null

Or on Windows (PowerShell):

Get-ChildItem -Path $HOME -Recurse -Filter "modern-founder-skills" -Directory -ErrorAction SilentlyContinue

Read the path it returns. Then cd to one level above that path, and run the update command again.

Common Error #2

You Renamed the Folder

If you renamed modern-founder-skills to something like 03_Modern Founder Skills or MFS, every update command fails because it's looking for the original name.

Easiest fix: rename it back. From your business folder root:

Mac / Linux

mv "03_Modern Founder Skills" modern-founder-skills

Windows

ren "03_Modern Founder Skills" modern-founder-skills

Replace 03_Modern Founder Skills with whatever you actually renamed it to. After that, the normal update command works.

Going forward - don't rename it. Every instruction in the course assumes the original name.
Common Error #3

Conflicts or Setup Script Fails

git pull reports conflicts

Usually means you edited a tracked file directly. Safe fix:

git stash && git pull && git stash pop

Setup script doesn't run

Manual copy, from your business folder root:

cp -R modern-founder-skills/.claude/skills/* .claude/skills/

Windows:

xcopy modern-founder-skills\.claude\skills .claude\skills\ /E /I /Y
Both do the same thing as running setup.sh / setup.bat - just manually. Run mkdir .claude/skills first if the destination doesn't exist yet.
Common Error #4

Folder Names With Spaces

Any folder name with a space in it needs quotes around it when you use it in a terminal command.

Right

cd "Business Docs"

Wrong

cd Business Docs

Without quotes, the terminal thinks Docs is a separate argument and fails.

The cleanest fix: when you name your business folder, use hyphens or underscores instead of spaces. my-business or my_business -- no quotes ever needed.

FAQ

  • Do I run the setup script every time I update?
    Yes. setup.sh on Mac / Linux, setup.bat on Windows. git pull alone only downloads the updates into the repo folder -- the setup script is what copies the updated skills into your .claude/skills/ folder. The one-line update command chains both for you.
  • Where should my CLAUDE.md live?
    At your business folder root, same level as modern-founder-skills/. Not inside the repo.
  • My skills disappeared after restarting Antigravity.
    Fully quit Antigravity (Cmd+Q / full close), then reopen. Just closing the window isn't enough.
  • Do I need to commit my changes to git?
    No. You're pulling updates, not pushing. Your own work stays on your machine - nothing goes public.
  • Can I have multiple businesses, each with their own setup?
    Yes. Each business folder is independent. Clone into each, run setup in each, separate CLAUDE.md files.
